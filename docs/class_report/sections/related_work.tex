\section{Related Work}

xView3 evaluates georeferenced vessel points in Sentinel-1 SAR rather than
classifying bounding boxes~\cite{paolo2022xview3}. A CenterNet-style heatmap
matches both the point annotations and the distance-based metric without
requiring synthetic box extents~\cite{zhou2019objects}. We use this
established detector form as a common task head.

ImageNet pretraining provides the generic transfer
baseline~\cite{steiner2021trainvit}. The ViT control uses a supervised AugReg
ViT-B/16 checkpoint. The CNN control uses ConvNeXt-V2-Base after fully
convolutional masked autoencoding and supervised ImageNet-1K
fine-tuning~\cite{woo2023convnextv2}. The remote-sensing checkpoints add two
source domains. SatDINO applies DINO self-distillation to fMoW-RGB optical
imagery~\cite{straka2025satdino}. SARMAE applies masked autoencoding to a
million-scale SAR corpus~\cite{liu2026sarmae}. Their objectives and source
corpora differ, so the ViT comparison measures the released checkpoints as
a whole. It cannot isolate sensing modality.

The CNN pair offers a cleaner modality contrast. Its two BigEarthNet-v2
models share the architecture, dataset family, and supervised land-cover
task. One model uses Sentinel-2 optical input and the other uses Sentinel-1
SAR input~\cite{sumbul2019bigearthnet,clasen2025reben}. Comparisons across
matched roles then test whether an observed within-track ranking persists
after the backbone family changes. Different pretraining histories still
limit that cross-track interpretation.
