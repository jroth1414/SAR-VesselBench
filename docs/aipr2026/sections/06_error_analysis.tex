\section{Analysis}
\label{sec:error-analysis}

\subsection{Operating thresholds and calibration}
\label{sec:threshold-transfer}

Each cell's operating point is selected on the training-time development
subset. The campaign's completion records retain the operating point of the
final development evaluation (Sect.~\ref{sec:gt-contract}), so we analyze
those final-evaluation records here. The recorded thresholds vary widely:
from \ThreshMinVit{} to \ThreshMaxVit{} across the ViT cells and from
\ThreshMinCnn{} to \ThreshMaxCnn{} across the CNN cells. The spread confirms
that a single shared threshold would misrepresent most arms and that the
per-cell sweep is doing real calibration work. At the final-evaluation
operating point, precision exceeds recall in \CellsPrecOverRecall{} of the
32 cells, so the swept points sit on the conservative side of the
precision--recall curve for most arms. The protocol also defines a
calibration-transfer diagnostic for the held-out stage, comparing the bound
threshold against an oracle test-optimal threshold after primary scoring;
that diagnostic becomes available only when the test matrix runs.

\subsection{Training dynamics and cost}
\label{sec:training-dynamics}

Early stopping with patience four development evaluations ended
\CellsEarlyStopped{} of the 32 cells before the 50-epoch cap. The median
best-checkpoint epoch is \MedianBestEpochVit{} for the ViT track and
\MedianBestEpochCnn{} for the CNN track. Fine-tuning cost is uneven between
the families: a core cell averaged \MeanCellHoursVit{} GPU-hours in the ViT
track and \MeanCellHoursCnn{} GPU-hours in the CNN track, with the full core
matrix consuming \ResultCoreGPUHours{} GPU-hours. Within each track, cost
scales with the label fraction, so the scarce-label cells that carry the
study's headline contrasts are also its cheapest.

Figure~\ref{fig:qualitative} shows the shared input representation and a
representative detector response on development scenes. The input triptych
illustrates the fixed $[\mathrm{VH},\mathrm{VV},\mathrm{VH}-\mathrm{VV}]$
construction: a vessel-scale bright return stands out against sea clutter in

during development-phase probe runs on this study's frozen splits, shows a
heatmap peak localized on a vessel-and-wake target at a raw score of 0.22.
Peaks this far below 1.0 on clear targets explain two protocol choices: the
permissive 0.05 candidate floor and the per-cell threshold sweep, without
which a fixed high threshold would silently drop true detections. These
panels illustrate mechanisms; they are not a scored sample, and the
protocol's registered false-positive taxonomy review is reserved for the
held-out stage. The qualitative cases are interpreted alongside, but do not
supersede, the quantitative findings in Sect.~\ref{sec:transfer-results}.
