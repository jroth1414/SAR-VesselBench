\begin{abstract}
Human-verified labels for vessels without matched Automatic Identification
System reports are scarce. We compare random, ImageNet, optical
remote-sensing, and SAR initialization within size-matched ViT-B/16 and
ConvNeXt-V2-Base tracks. All 32 planned cells share the input, point detector,
optimization schedule, nested scene budgets, seed, and strict-FP32 H100
runtime.

The result snapshot contains one record for every planned experiment. A record
carries its cell identifier, state, completed epoch, duration, checkpoint
markers, and a development metric only after verified completion. Hardware,
source revision, environment, strict-FP32 state, and frozen-artifact hashes
bind the cohort. The generator refuses mixed hardware, duplicate or missing
identifiers, non-finite metrics, and fraction-wise comparisons before all eight
roles close.

The present evidence has four limits. First, development F1 supports model
selection rather than held-out performance. Second, one fixed seed supplies no
run-to-run variance estimate. Third, the ViT optical/SAR pair also changes the
pretraining objective; only the CNN BigEarthNet pair closely matches the
architecture, dataset family, and source task. Fourth, scene-level separation
does not establish transfer to a new geographic region. Any admitted values are
point estimates without confidence intervals; test and human-verified scoring remain deferred.
