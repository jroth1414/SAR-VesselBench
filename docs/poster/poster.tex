\block{}{%
  \centering\fontsize{36}{46}\selectfont
  \textbf{Short answer: not consistently.} With 12 labeled scenes every
  pretrained encoder beats random initialization, but SAR pretraining beats
  optical only for the CNN, and only while labels are scarce.\par}

\block{Motivation}{
  \begin{itemize}
    \item \textbf{Dark vessels} have no matching AIS report. Sentinel-1 SAR
      \refn{2} sees them at night and through cloud.
    \item Vessels fill a few pixels in a 25{,}000-pixel scene. Sea clutter
      and coastlines give strong false returns.
    \item \textbf{Human-verified labels are scarce.} Pretraining can lower
      the label cost, but which source domain helps most, and does the
      answer depend on the backbone?
  \end{itemize}
}

  one 800-pixel chip (8 $\times$ 8\,km).\par}

  \begin{itemize}
    \item 150 frozen study scenes: \textbf{111 train, 23 dev, 16 test}.

    \item Input [VH, VV, VH$-$VV] in dB, 10\,m pixels.
  \end{itemize}
}

\block{Findings}{
  \begin{center}
    {\fontsize{64}{70}\selectfont\bfseries\color{roleimagenet}\PNGainTwelveCiAboveZero{} / \PNGainTwelveComparisons}\par
    \vspace{3mm}
    pretrained-vs-random comparisons at 12 training scenes have a 95\%
    interval above zero.\par
  \end{center}
  \vspace{3mm}
  \begin{enumerate}
    \item \textbf{Pretraining pays off with few labels.} Gains at 12
      scenes: \PNTestGainTwelveMin{} to \PNTestGainTwelveMax{} test F1,
      \PNFinalGainTwelveMin{} to \PNFinalGainTwelveMax{} verified F1.
    \item \textbf{SAR beats optical only for the CNN, and only with few
      labels:} \PNTestCnnSarMinusOptTen{} \PNTestCnnSarMinusOptTenCi{} test
      F1 at 12 scenes, but \PNFinalCnnSarMinusOptHundred{}
      \PNFinalCnnSarMinusOptHundredCi{} verified F1 at 111. ViT: no stable
      order.
    \item \textbf{The input adapter matters.} With a seeded 3-channel stem
      instead of band slicing, BigEarthNet-S2 beats random at every budget
      (\PNCnnOpticalTestGainMin{} to \PNCnnOpticalTestGainMax{} test F1).
    \item \textbf{The coastal gap is a label gap.} Only
      \PNTrainNearShorePct{} of training vessels lie within 2\,km of shore,
      against \PNFinalNearShorePct{} of verified ones.
  \end{enumerate}
}
\block{Limits}{
  \begin{itemize}
    \item One seed per cell; 8 dev scenes pick checkpoints and thresholds.
    \item Monotonicity gate failed: two SAR test curves drop by more than
      0.02 as labels grow.
    \item Checkpoints differ in objective and corpus, not only domain.
  \end{itemize}
}
\block{Open questions \& next steps}{
  \begin{itemize}
    \item How do multi-sensor foundation models such as CROMA \refn{11}
      and DOFA \refn{12} fare against single-source checkpoints?
    \item Does SAR pretraining help where optical cannot: near shore and
      for small dark vessels?
    \item Why does SARMAE peak at its first evaluation with 28 or fewer
      scenes?
    \item \textbf{Next:} near-shore training labels, a shoreline input
      channel, several seeds, and matched pretraining objectives across
      sensors.
  \end{itemize}
}
