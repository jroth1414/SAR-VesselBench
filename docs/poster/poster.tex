\block{Findings}{
  \begin{enumerate}[itemsep=0.3em]
    \item \textbf{Pretraining pays off with few labels:}
      \PNTestGainTwelveMin{} to \PNTestGainTwelveMax{} test F1 at 12 scenes.
    \item \textbf{SAR pretraining rarely wins:}\par\vspace{2mm}
      \includegraphics[width=0.86\linewidth]{poster_scoreboard.pdf}
    \item \textbf{The input adapter matters:} a seeded 3-channel stem lifts
      BigEarthNet-S2 above random at every budget.
    \item \textbf{No detector works near shore:} recall
      $\leq$\,\PNFinalNearShoreRecallMax{} within 2\,km in every cell.
  \end{enumerate}
}

\block[titleoffsety=14mm,bodyoffsety=14mm]{Limits}{
  \begin{itemize}[itemsep=0.25em]
    \item One seed per cell; 8 dev scenes for selection.
    \item Machine-made test labels; in-region test scenes.
    \item Checkpoints also differ in objective and data.
    \item In-region test: Sentinel-1 revisits put some test scenes near
      training scenes, so test F1 measures in-region generalization, not
      generalization to new regions.
  \end{itemize}
}
\block[titleoffsety=20mm,bodyoffsety=20mm]{Open questions \& next steps}{
  \begin{itemize}[itemsep=0.25em]
    \item Would joint SAR + optical foundation models win?
    \item Does SAR trail ImageNet with matched pretraining?
    \item \textbf{Next: make detectors work near shore} (recall
      $\leq$\,\PNFinalNearShoreRecallMax{} within 2\,km): train on
      human-labeled near-shore vessels, add a distance-to-shore input,
      and set shore-aware thresholds.
  \end{itemize}
}
